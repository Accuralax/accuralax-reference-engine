# CyberFusion Creative Studio Workspace

## Workspace modes
- Document: rich text, sections, tables, templates, versions, approvals.
- Content: posts, articles, emails, scripts, campaigns and reusable copy.
- Image: prompt, generation, editing, variations, brand treatment and assets.
- Video: script, storyboard, scenes, captions, timeline and export.
- Presentation: slides, layouts, speaker notes, themes and export.

## Layout
1. Left tool rail: Create, Templates, Brand, Media, Elements, Text, Tools.
2. Centre canvas: the active document/design/media composition.
3. Right agent panel: Supervisor, Founder, Specialist, Knowledge, QA, Approval.
4. Bottom context bar: undo/redo, zoom, version, status, reference ID and export.

## Shared AI actions
Rewrite, expand, shorten, simplify, professionalise, summarise, translate, add/remove section, apply theme and consistency check.

## Safety and control
- Agent actions are bounded by the existing permission system.
- Credentials never enter creative content or trace details.
- Export remains approval-aware for governed documents.
- Every workflow receives a CyberFusion reference ID and agentic trace.
- Media generation providers remain pluggable; no unverified provider is hard-coded.

## Progressive enhancement
The first UI must work without WebGL. Three.js/Anime.js can enhance the workspace later with the planned multi-window 3D agent scene without becoming a dependency for basic editing.
