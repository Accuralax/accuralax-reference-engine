# CyberFusion Solutions AI Agent Roadmap

## Phase 1 — Foundation (current)
- Deterministic service routing and service knowledge
- Skills registry and safety rules
- Consent-gated handoff
- Reference IDs and audit events
- Persistent local conversation sessions
- Transport-neutral gateway
- Local Ollama/Qwen runtime
- Dependency and readiness validation

## Phase 2 — Agentic Runtime
- LangGraph state machine
- Supervisor graph and specialist agents
- Bounded sub-agents
- Formal Skill contracts
- MCP capability gateway
- Graph checkpoints, retries, circuit breakers

## Phase 3 — RAG
- Ingestion, normalization, chunking, metadata
- Embedding abstraction and vector store
- Retrieval and reranking
- Provenance/citations
- RAG evaluation
- Stale/conflict detection

## Phase 4 — Self-Check & Self-Healing
- Health registry
- Diagnostics and incident model
- Repair-plan schema
- Sandbox patch runner
- Regression gate
- Rollback manager
- Bounded repair loops

## Phase 5 — MCP Ecosystem
- GitHub
- Claude Code
- Obsidian
- Remote Desktop Commander
- Supabase
- Vercel
- Approved business-system adapters
- Permission registry

## Phase 6 — UI Verse
- shadcn/ui + Tailwind
- Multi-window workspace
- Anime.js motion
- 3D agent carousel / constellation
- Live orchestration graph
- RAG / knowledge map
- Health center
- Audit / reference explorer
- WebGL fallback and accessibility

## Phase 7 — External Integrations
- WhatsApp
- Make
- HubSpot
- Website and social channels
- Authenticated webhooks
- Idempotency, retries, dead-letter handling

## Phase 8 — Production Hardening
- Observability and load testing
- Security and prompt-injection testing
- Disaster recovery and backup/restore
- Deployment/change gates
- Runbooks and operational controls
